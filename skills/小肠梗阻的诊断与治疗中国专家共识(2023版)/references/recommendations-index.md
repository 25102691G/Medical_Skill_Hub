# 小肠梗阻的诊断与治疗中国专家共识(2023版)重要信息索引

## 一、小肠梗阻的诊断

- **推荐意见1**：明确小肠梗阻的分类是诊断与治疗的基础（A，强）。分类：病因（机械性、动力性、血运性、假性），血运（单纯性、绞窄性），程度（完全性、不完全性），部位（高位、低位）。
- **推荐意见2**：详细病史询问和体格检查是小肠梗阻初步诊断的临床依据（A，强）。
- **推荐意见3**：必要的实验室检查对小肠梗阻的诊断有重要参考价值（C，强）。CRP>75 g/L和白细胞>10×10⁹/L提示腹膜炎可能。
- **推荐意见4**：血D-乳酸盐和脂肪酸结合蛋白作为判断急性肠损伤的指标，对排除肠绞窄有重要价值（C，弱）。D-乳酸盐反映肠道通透性；IFABP灵敏度72%，特异度73%。
- **推荐意见5**：腹部X线立卧位平片和超声检查对肠梗阻初步诊断具有重要价值（C，强）。X线灵敏度约70%；超声灵敏度92%，特异度93%。
- **推荐意见6**：平扫或增强螺旋CT作为小肠梗阻的首选诊断检查（A，强）。判断绞窄、穿孔、坏死准确性达92%。CTA对肠系膜血管栓塞灵敏度93.3%，特异度95.9%。CTE可显示肠黏膜及肠壁状况。
- **推荐意见7**：MRI作为CT不适用时和鉴别小肠黏膜炎性病变的重要替代检查（B，强）。MRE可评估克罗恩病、肠瘘及小肠肿瘤。
- **推荐意见8**：水溶性造影剂检查对明确小肠梗阻的部位和程度有重要意义（A，强）。预测梗阻解除灵敏度92%，特异度93%；8 h后检查准确性显著提高。

## 二、小肠梗阻的非手术治疗

- **推荐意见9**：非手术治疗的策略和原则（A，强）。无腹膜炎、肠坏死及肠缺血时，先行非手术治疗3~5 d。原则：禁食、补液、胃肠减压、解痉（避免止痛）、动态监测。
- **推荐意见10**：生长抑素可改善症状，提高非手术治疗效果（B，强）。可减少消化液分泌90%。
- **推荐意见11**：肠梗阻导管减压效果优于鼻胃管，可提高非手术治疗效果（B，强）。联合药物治疗对70%~90%患者有效。
- **推荐意见12**：水溶性造影剂可减轻肠壁水肿，提高非手术治疗效果（A，强）。高渗性造影剂促进肠壁液体转移至肠腔，刺激蠕动。
- **推荐意见13**：营养治疗能改善非手术治疗的预后（A，强）。先经鼻空肠管滋养型肠内营养，逐步过渡。不能满足60%目标量时补充肠外营养。
- **推荐意见14**：菌群移植能恢复肠道菌群紊乱，改善麻痹性或假性梗阻等患者的治疗效果（C，弱）。当扩张小肠直径<2.5 cm、肠内营养可耐受目标量50%时，行菌群移植。
- **推荐意见15**：术后早期炎性肠梗阻（EPII）推荐非手术治疗（B，强）。87%在2周内对非手术治疗有反应。
- **推荐意见16**：慢性假性肠梗阻（CIPO）推荐非手术治疗为主、手术治疗为辅（B，强）。诊断基于影像和内镜排除解剖梗阻；手术仅用于高度扩张、缺血穿孔或无法恢复肠内营养时。

## 三、小肠梗阻的手术治疗

- **推荐意见17**：开通小肠梗阻绿色通道和建立多学科团队，是提高急诊手术疗效的保证（C，强）。保证6 h内完成初步诊断、围急诊手术期处理、高级生命支持和手术。
- **推荐意见18**：损伤控制性外科理念可以提高急诊手术的安全性和疗效（B，强）。适用于严重营养不良、血流动力学不稳定、肠坏死及严重腹腔感染者；施行相对简单的肠切除肠造口，二期还纳。
- **推荐意见19**：绞窄性小肠梗阻明确诊断后立即手术治疗（A，强）。典型表现：急性持续性腹痛伴阵发加剧、腹膜刺激征、孤立巨大肠袢或影像学“鸟嘴征”“假肿瘤征”、血性腹腔穿刺液、血磷升高（肠坏死3 h后）或发热伴白细胞>18×10⁹/L。
- **推荐意见20**：腹腔镜微创手术可作为粘连性肠梗阻的术式选择（A，强）。中转开腹率20.0%~51.9%，肠损伤发生率6.5%~18.0%。禁忌：腹膜炎、多次腹部手术史、小肠直径>4 cm、气腹禁忌证等。
- **推荐意见21**：克罗恩病合并小肠梗阻的患者，应结合临床特点制定综合手术策略（B，强）。纤维性狭窄反复梗阻或依赖肠外营养者择期手术；急性肠缺血或弥漫性腹膜炎急诊手术；多节段病变行狭窄成形术，避免大面积切除。
- **推荐意见22**：腹茧症并发小肠梗阻推荐粘连松解联合肠排列术（C，强）。开腹手术；排列管支撑7~14 d肠管粘连固定后拔除。极少发生血运障碍，不完全手术增加再手术困难。
- **推荐意见23**：放射性肠损伤合并小肠梗阻建议手术治疗（C，强）。根据基础状态、病变肠管位置选择小肠造口或肠切除吻合；末端回肠病变切除应包括回盲部，以保证血供、降低吻合口漏及远期梗阻发生率。
