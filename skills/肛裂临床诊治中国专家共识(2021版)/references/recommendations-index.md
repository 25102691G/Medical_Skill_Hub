# 肛裂临床诊治中国专家共识(2021版)重要信息索引

## 诊断评估

**推荐意见1:** 患者应常规接受专业的诊断评估，尤其是侧方的肛裂应排除其他肛周疾病。(推荐强度:强烈推荐)

- 诊断基于症状及局部视诊、指检、肛门镜检查。
- 分类：急性(<6~8周，单纯撕裂) vs 慢性(哨兵痔、肛乳头肥大、内括约肌纤维裸露、皮下瘘)。
- 按括约肌压力分：痉挛型、正常型、松弛型。
- 疼痛明显者可在表面麻醉或麻醉下检查。
- 肠镜排除肿瘤、炎性肠病；腔内超声评估括约肌形态(复发再术前或松弛型术前)。
- 年龄>65岁或非典型症状/侧方肛裂：警惕克罗恩病、结核、梅毒、艾滋病、银屑病、肛管癌等，需进一步检查(结肠镜、活检)。

## 治疗

### 基础治疗

**推荐意见2:** 急性或慢性肛裂患者应以基础治疗为主。(推荐强度:推荐)

- 增加膳食纤维(25~30 g/d)和水分摄入、增加运动。
- 保守治疗为首选，安全无不良反应。

**推荐意见3:** 容积性或渗透性泻剂可用于治疗肛裂。(推荐强度:推荐)

- 容积性泻剂：纤维素补充剂(小麦纤维素颗粒、甲基纤维素等)，滞留水分，增加粪便体积。
- 渗透性泻剂：聚乙二醇、不被吸收的糖类。
- 软化粪便，减轻对裂口的刺激和损伤，促进愈合。

**推荐意见4:** 温水坐浴可用于治疗肛裂，防止复发。(推荐强度:推荐)

- 温水(36~40℃)坐浴每次10~15 min，每日2次或每次排粪后。
- 减轻括约肌痉挛、改善血液循环、缓解疼痛。

### 中医治疗

**推荐意见5:** 中药可用于治疗肛裂。(推荐强度:强烈推荐)

- 辨证论治：便秘用滋阴降火、行气润肠方；出血用三七类止血药。
- 局部熏洗坐浴：清热解毒、活血化瘀、利湿消肿，促进愈合。
- 外用栓剂、油膏、散剂可促进裂口愈合、预防或控制感染。

### 药物治疗

**推荐意见6:** 一氧化氮供体硝酸甘油(GTN)外用可缓解肛裂导致的疼痛，促进愈合。然而，存在头痛风险的患者需谨慎使用。(推荐强度:推荐)

- 浓度：0.05%~0.4%；用法：每日2次，连续6~8周。
- 头痛发生率20%~30%，剂量依赖性；可通过口服止痛药或4~5天内逐渐加量预防。
- 0.4%浓度愈合率(54.1%)高于0.2%(40.4%)；长期复发率51%~67%。

**推荐意见7:** 钙离子通道阻滞剂(CA)外用可缓解肛裂导致的疼痛，促进愈合，且不良反应少，可作为肛裂的一线治疗药物。(推荐强度:建议)

- 常用药物：地尔硫卓、硝苯地平；2%软膏，每日2次，连续6~8周。
- 愈合率65.0%~94.5%；头痛和肛门瘙痒发生率约10%。
- 局部用药优于口服，疗效与硝酸盐类相当，不良反应更少。

**推荐意见8:** 局部注射肉毒杆菌毒素(BT)用于肛裂的治疗尚处研究阶段，缺少统一的诊疗规范，需谨慎使用。(推荐强度:建议)

- 剂量：通常30~50单位，注射于裂口两侧内括约肌。
- 治愈率73%(较安慰剂有效)；3年复发率40%~50%。
- 不良反应：气体失禁10%~18%，粪便失禁5%。

### 手术治疗

**推荐意见9:** 肛裂切除术适用于慢性肛裂及伴发不同程度并发症的肛裂患者。(推荐强度:强烈推荐)

- 切除裂口溃疡及边缘(送病理)，必要时行推移瓣肛门成形术。
- 避免后正中括约肌切开(锁眼畸形、污粪风险)。
- 多中心研究：痊愈时间7.5周，满意度91%，并发症4%(尿潴留、尿路感染、粪便嵌塞)。
- 长期随访：复发率11.6%，对失禁影响小。
- 与侧方内括约肌切开术比较：复发率3.1%，气体失禁6.3%。

**推荐意见10:** 侧方内括约肌切开术是目前手术治疗肛裂的首选方式，适用于括约肌高张力的肛裂，但对于存在括约肌损伤风险的患者不建议采用。(推荐强度:强烈推荐)

- 直视(开放式)或手指引导(闭合式)切开齿状线以下内括约肌。
- 总体愈合率92%~100%，早期和远期失禁率3.3%~16.0%。
- 长期随访：气体失禁6%、肛门溢液8%、排粪失禁1%。
- 术前需评估肛门功能(指检/测压)。女性风险较高(肛管短、分娩、既往手术)。
- 改良术式(按裂口长度切开)疗效相近，失禁率<10%。避免后正中切开。

**推荐意见11:** 推移皮瓣肛门成形术适用于肛门括约肌张力低或存在高失禁风险的患者。(推荐强度:推荐)

- 切除纤维化区域，游离皮瓣覆盖缺损，与黏膜缝合(V-Y、U形、菱形、House瓣)。
- 并发症：皮瓣坏死、缝合口开裂、感染。
- 与括约肌切开术比较：治愈率无显著差异(98% vs 100%)，失禁风险低(0~3.3%)，开裂发生率5.9%。

### 术后管理

**推荐意见12:** 术后有效的创面管理，有助于创面的修复、避免并发症的发生。(推荐强度:推荐)

- 止血：有出血风险者围手术期使用矛头蝮蛇血凝酶等。
- 促进愈合：开放性伤口使用促生长药物，中药熏洗坐浴(清热利湿、活血化瘀、生肌)；闭合式伤口避免坐浴。

### 特殊人群肛裂治疗

**推荐意见13:** 儿童、孕妇、克罗恩病相关肛裂患者，需注意其特殊人群的治疗特点，以保守治疗为主。(推荐强度:强烈推荐)

- 克罗恩病相关：35% CD患者有肛裂，若位置异常、基底宽或有脓液，需警惕。术前应行肠镜、小肠镜、肛周MRI及活检。保守治疗(药物、坐浴)首选，慎行括约肌切开术(易加重失禁)。
- 儿童：68%~86%功能性便秘伴排粪疼痛，早期治疗防慢性化。软化粪便(口服小麦纤维素颗粒等)，外用CCB或GTN(CCB更优，复发率低)，BT亦可重复注射。不建议手术。
- 产后：常累及肛门前侧，与便秘、激素变化及会阴动态相关。约1/3妇女孕期或产后有肛周症状。推荐补充膳食纤维软化粪便。
