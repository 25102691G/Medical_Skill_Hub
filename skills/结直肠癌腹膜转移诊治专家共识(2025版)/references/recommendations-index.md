# 结直肠癌腹膜转移诊治专家共识(2025版)重要信息索引

## Definition of Colorectal Cancer Peritoneal Metastasis

- **Recommendation 1**: 结直肠癌腹膜转移是指原发灶的癌细胞脱落种植于腹膜，形成新的肿瘤病灶。(证据质量：A;推荐级别：强推荐)
- **Recommendation 2**: 结直肠癌初诊时即伴有腹膜转移为同时性腹膜转移，根治术后发生的腹膜转移为异时性腹膜转移，经规范的术前影像学检查未发现，而术中诊断的腹膜转移为临床隐匿性腹膜转移。(证据质量：A;推荐级别：强推荐)

## Diagnosis

- **Recommendation 3**: 结直肠癌腹膜转移典型症状是难治性腹水、持续性肠梗阻和顽固性腹痛。(证据质量：A;推荐级别：强推荐)
- **Recommendation 4**: 全腹+盆腔薄层增强CT作为结直肠癌腹膜转移的首选影像学检查方法。(证据质量：A;推荐级别:强推荐)
  - 薄层增强CT灵敏度25%~100%，特异度78%~100%，对<5mm结节灵敏度仅11%~48%。
  - 典型征象：腹膜不均匀增厚伴腹膜结节；网膜或大网膜多发条索、结节；肠系膜结节状增厚；腹盆腔大量积液等直接征象以及胆管、输尿管和肠管扩张等间接征象。CT多平面重建有助于估算术前CT-PCI评分。
  - PET/CT灵敏度78%~97%，特异度55%~90%，但印戒细胞癌、黏液腺癌和低分化腺癌等高腹膜转移组织学类型GLUT1表达极低，可能出现假阴性。成纤维细胞激活蛋白抑制剂作为PET/CT新型代谢造影剂可提高诊断率。
  - MRI（低张、呼吸训练、DWI）灵敏度90.0%，特异度95.5%。PET/MRI具有低辐射、高软组织分辨率，可同机分析DWI与PET探针显像。
  - 胃肠道动态造影可观察小肠蠕动、分布及系膜挛缩情况。
- **Recommendation 5**: 血清肿瘤标志物可作为结直肠癌腹膜转移的辅助诊断手段。(证据质量：A;推荐级别：强推荐)
  - CEA、CA125、CA19-9联合检测提高灵敏度和特异度。CA125阳性预测值显著高于其他标志物，辅助判断腹水和肿瘤负荷。持续性肿瘤标志物升高且无其他部位转移时需高度怀疑腹膜转移。
- **Recommendation 6**: 手术探查(开腹或腹腔镜)是诊断可疑腹膜转移及评估腹膜转移程度的最可靠手段，有助于临床治疗方案的决策。(证据质量：A;推荐级别:强推荐)
  - 对临床隐匿性腹膜转移灵敏度和特异度均较高，可同时行腹腔游离癌细胞检测和腹膜结节活检。
- **Recommendation 7**: PCI和PSDSS可评估结直肠癌腹膜转移的肿瘤负荷。(证据质量：A;推荐级别:强推荐)
  - PCI：将腹盆腔分为13个区域，每个区域LS评分：LS0:未见肿瘤; LS1:≤0.5cm; LS2:0.5~5.0cm; LS3:>5.0cm或融合。PCI为各区域LS总和(0~39)。PCI越高，行彻底CRS可能性越小，预后越差。
  - PSDSS评分标准：

| 评价指标 | 评分(分) |
|---------|---------|
| **临床症状** | |
| 无 | 0 |
| 轻微 | 1 |
| 严重 | 6 |
| **PCI** | |
| <10 | 1 |
| 10~20 | 3 |
| >20 | 7 |
| **组织病理学特征** | |
| G1/2, N-, L-, V- | 1 |

> 注：临床症状轻微：体质量减轻<10%，轻度腹痛，少量腹水；严重：体质量减轻≥10%，持续腹痛，肠梗阻，症状性腹水；PCI通过影像或术中评估；N-/+:淋巴结阴性/阳性，L-/+:淋巴管侵犯阴性/阳性，V-/+:血管侵犯阴性/阳性。

PSDSS分期：Ⅰ期2~3分；Ⅱ期4~7分；Ⅲ期8~10分；Ⅳ期>10分。PSDSS是独立预后因素。

## Treatment

### Systemic Therapy

- **Recommendation 8**: 全身系统治疗参考转移性结直肠癌的治疗方法，包括化疗、靶向治疗和免疫治疗等方式。(证据质量：A;推荐级别：强推荐)
  - **一线化疗方案**：
    - mFOLFOX6 (2周/疗程)：奥沙利铂85 g/m² 静脉滴注2h d1；亚叶酸钙400 mg/m² 静脉滴注2h d1；氟尿嘧啶400 mg/m² 静脉推注 d1, 1200 mg/(m²·d) 持续静脉滴注 d2 (总量2400 mg/m² 持续46~48h)。
    - CAPEOX (3周/疗程)：奥沙利铂130 mg/m² 静脉滴注>2h d1；卡培他滨1000 mg/m² BID 口服 d1~14。
    - FOLFIRI (2周/疗程)：伊立替康180 mg/m² 静脉滴注>30~90min d1；亚叶酸钙400 mg/m² 静脉滴注2h (伊立替康后接) d1；氟尿嘧啶400 mg/m² 静脉推注 d1, 1200 mg/(m²·d) 持续静滴 d2 (总量2400 mg/m² 持续46~48h)。
    - FOLFOXIRI (2周/疗程)：伊立替康165 mg/m² 静滴 d1；奥沙利铂85 mg/m² 静滴 d1；亚叶酸钙400 mg/m² 静滴 d1；氟尿嘧啶总量2400~3200 mg/m² d1 持续静滴48h。
  - **二线化疗方案**：
    - mFOLFOX6或CAPEOX（剂量同上），适用于一线伊立替康治疗失败。
    - FOLFIRI（剂量同上），适用于一线奥沙利铂治疗失败。
    - 奥沙利铂+雷替曲塞 (2周/疗程)：奥沙利铂85 mg/m² 静滴2h d1；雷替曲塞2 mg/m² 静滴15min d1，适用于氟尿嘧啶不耐受。
    - 伊立替康+雷替曲塞 (2周/疗程)：伊立替康180 mg/m² 静滴>30~90min d1；雷替曲塞2 mg/m² 静滴15min d1，适用于氟尿嘧啶不耐受。
  - **靶向治疗**：
    - 贝伐珠单克隆抗体：用于原发灶右半结肠或左半结肠RAS/BRAF突变型。A. 7.5 mg/kg 静滴 d1 (3周/疗程)。B. 5 mg/kg 静滴 d1 (2周/疗程)。
    - 西妥昔单克隆抗体：用于原发灶左半结直肠且RAS/BRAF野生型。A. 首次400 mg/m² 静滴>2h，后续250 mg/m² 静滴>60min (1周/疗程)。B. 500 mg/m² 静滴>2h d1 (2周/疗程)。
    - 二线：贝伐珠单抗（方案剂量同前）适用于一线治疗失败，无论RAS/BRAF表型、无论一线是否联合西妥昔单抗或贝伐珠单抗。西妥昔单抗（方案剂量同前）仅适用于一线未联合西妥昔单抗且RAS/BRAF野生型。
  - **免疫治疗**：MSI-H/dMMR型结直肠癌对免疫治疗有效；MSI-L/MSS/pMMR型目前无高级别证据。

### Intraperitoneal Chemotherapy

- **Recommendation 9**: 常用的腹腔化疗方式主要包括腹腔热灌注化疗和常温腹腔灌注化疗等形式。(证据质量：A;推荐级别：强推荐）
- **Recommendation 10**: 腹腔热灌注化疗建议选择闭合式，灌注速度为400~600 mL/min,有效灌注液为4~6 L，以腹腔充盈为原则，并维持腹腔内化疗药液温度为(43±0.1)℃，持续60~90 min,术后根据患者具体情况可多次灌注，每次治疗间隔24h。(证据质量：A;推荐级别：强推荐)
  - 原理：43℃持续浸泡不可逆损伤癌细胞，正常组织可耐受47℃1h。热效应增强化疗药物毒性和渗透性；灌洗冲刷清除游离癌细胞；热休克蛋白激活抗瘤免疫。
- **Recommendation 11**: 腹腔化疗常用的药物包括5-氟尿嘧啶、奥沙利铂和丝裂霉素等。(证据质量:B;推荐级别：弱推荐）
  - 药物选择应根据原发肿瘤化疗药物、敏感药或药敏结果，选择穿透性高、分子量大、半衰期长、腹膜刺激小的药物。常用药物还包括伊立替康、雷替曲塞、洛铂、顺铂、重组改构人肿瘤坏死因子等。目前无统一剂量和频次标准，无腹腔灌注化疗药物适应证，建议超适应证使用备案并签署知情同意书。

### Cytoreductive Surgery (CRS)

- **Recommendation 12**: 结直肠癌腹膜转移PCI≤20时可考虑行肿瘤细胞减灭术，尽可能完全将腹腔内肉眼可见肿瘤切除，降低肿瘤负荷。(证据质量：A;推荐级别：强推荐）
  - 探查顺序：肝圆韧带→大网膜→小网膜→右上腹→左上腹→膈面腹膜→侧壁腹膜→右髂窝→左髂窝→盆底腹膜→小肠系膜。壁腹膜整片剥脱，必要时切除胆囊、脾脏、直肠及子宫附件。PCI>20者预后差、并发症和死亡率高，应谨慎。
- **Recommendation 13**: 细胞减灭程度(CC)评分可评估肿瘤细胞减灭术后肿瘤残余程度。(证据质量：A;推荐级别:强推荐)
  - CC-0: 无可见腹膜结节；CC-1: 残留结节<2.5 mm；CC-2: 2.5 mm~2.5 cm；CC-3: >2.5 cm或不可切除灶。CC-0/1为满意CRS。

### Multidisciplinary Combined Treatment

- **Recommendation 14**: 结直肠癌腹膜转移的治疗应依据肿瘤负荷(PCI)选择全身系统治疗、腹腔灌注化疗、肿瘤细胞减灭术不同组合的综合治疗模式。(证据质量：A;推荐级别：强推荐)
  - PCI>20：采用全身系统治疗+腹腔灌注化疗进行转化治疗，若PCI降至≤20且符合条件可考虑行CRS；即使未能转化也可作为姑息治疗延长生存。
  - PCI≤20：采取CRS+腹腔灌注化疗+全身系统治疗。PCI较低、CRS可达CC0-1者，目前无高级别新辅助治疗证据；术后治疗至关重要。

## Prevention

- **Recommendation 15**: 结直肠癌腹膜转移的高危因素包括结直肠癌原发灶穿孔，伴发同时性卵巢转移，原发灶非R0切除，TNM分期为T4期和(或)N+，术中淋巴结清扫数目<12枚，组织类型分化差(黏液腺癌等)，腹腔灌洗液检测游离癌细胞阳性。(证据质量：A;推荐级别:强推荐)
  - 其他危险因素：发病年龄小，肿瘤侵及肠壁神经，急诊手术。
- **Recommendation 16**: 局部进展期结直肠癌规范的综合治疗，术中严格无瘤操作，防止医源性腹腔播散转移是预防腹膜转移的有效手段。(证据质量：A;推荐级别：强推荐)
  - 高危患者：规范围手术期治疗降低风险；术中严格无瘤操作；预防性腹腔热灌注化疗（HIPEC）可能降低腹膜转移发生率，但缺乏高级别证据，建议以临床研究形式施行。
