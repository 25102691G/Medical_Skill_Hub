# 中国急性胰腺炎诊治指南(2021)重要信息索引

## 急性胰腺炎的诊断

### 流行病学与病因学
- 发病率存在地区差异，为(4.9\~73.4)/10万，呈上升趋势。
- 主要病因：胆石症（我国首位），其次为高甘油三酯血症、过度饮酒。其他：药物、ERCP术后、高钙血症、感染、遗传、自身免疫疾病、创伤等。
- 病因控制有助于缓解病情、改善预后并预防复发。

### 临床表现
- 典型症状：急性发作的持续性上腹部剧烈疼痛，常向背部放射，伴腹胀、恶心、呕吐，呕吐后疼痛不缓解。
- 严重者可出现休克表现（心动过速、低血压、少尿）、精神状态改变。
- 体征：轻者腹部轻压痛；重者腹膜刺激征，偶见Grey-Turner征、Cullen征。
- 可并发呼吸、肾功能障碍等。
- 实验室：血清淀粉酶和/或脂肪酶升高，脂肪酶特异度优于淀粉酶；升高程度与严重程度无关。
- 影像学：腹部CT为重要检查，早期表现为胰腺水肿、胰周渗出、坏死等。

### 诊断标准
- **推荐意见1**：符合以下3项中的2项可诊断：(1)上腹部持续性疼痛；(2)血清淀粉酶和/或脂肪酶浓度高于正常上限值3倍；(3)腹部影像学符合急性胰腺炎改变。（证据等级：高；推荐强度：强烈推荐）

### 影像学检查
- 典型CT表现是诊断依据，但发病初期不能反映严重程度；除非确诊需要，CT应在发病72h后进行。
- 增强CT可准确反映胰腺坏死及其范围，改良CT严重指数（MCTSI）评估严重程度。

**表1 改良CT严重指数(MCTSI)评分标准**
| 特征 | 评分(分) |
|------|----------|
| **胰腺炎症反应** | |
| 正常胰腺 | 0 |
| 胰腺和(或)胰周炎性改变 | 2 |
| 单发或多个积液区或胰周脂肪坏死 | 4 |
| **胰腺坏死** | |
| 无胰腺坏死 | 0 |
| 坏死范围≤30% | 2 |
| 坏死范围>30% | 4 |
| **胰外并发症**（胸腔积液、腹水、血管或胃肠道受累等） | 2 |

- MRI：用于碘造影剂过敏、肾功能不全、年轻/怀孕患者；判断胰腺水肿灵敏度优于CT，但对气泡诊断差。
- 可疑胆源性AP：入院时或发病48h内行超声检查；MRCP或EUS有助于发现隐匿性胆道结石。

- **推荐意见2**：除非确诊需要，发病初期不推荐增强CT扫描。（证据等级：中；推荐强度：强烈推荐）
- **推荐意见3**：可疑胆源性AP，入院时或发病初期常规行超声检查明确胆道结石。（证据等级：中；推荐强度：强烈推荐）

### 严重程度分级
- 常用RAC分级，DBC分级也使用。

**表2 急性胰腺炎分级诊断系统**
| 分级系统 | 轻症 | 中度重症 | 重症 | 危重症 |
|----------|------|----------|------|--------|
| RAC分级 | 无器官功能障碍和局部并发症 | 一过性(≤48h)器官功能障碍和/或局部并发症 | 持续性(>48h)器官功能障碍 | 无 |
| DBC分级 | 无器官功能障碍和胰腺(胰周)坏死 | 一过性(≤48h)器官功能障碍和/或无菌性坏死 | 持续性(>48h)器官功能障碍或感染性坏死 | 持续性(>48h)器官功能障碍和感染性坏死 |

- RAC中器官功能障碍采用改良Marshall评分，任何器官评分≥2分即存在。

**表3 改良Marshall评分系统**
| 器官和系统 | 0分 | 1分 | 2分 | 3分 | 4分 |
|------------|-----|-----|-----|-----|-----|
| 呼吸(PaO₂/FiO₂) | >400 | 301\~400 | 201\~300 | 101\~200 | ≤101 |
| 血肌酐[μmol/L(mg/dl)] | ≤134(≤1.4) | 134\~169(1.4\~1.8) | 170\~310(1.9\~3.6) | 311\~439(3.6\~4.9) | >439(>4.9) |
| 收缩压(mmHg) | >90 | <90，输液有应答 | <90，输液无应答 | <90，pH<7.3 | <90，pH<7.2 |

- DBC依据SOFA评分诊断器官功能障碍。

- **推荐意见4**：RAC和DBC均可用于严重程度分级，在预测病死率、ICU入住率及住院时间上无明显差异。（证据等级：中；推荐强度：强烈推荐）
- **推荐意见5**：CAP（持续性器官功能障碍+感染性坏死）病死率高，需高度重视。（证据等级：中；推荐强度：强烈推荐）

### SAP的预测
- 实验室指标（血细胞比容、尿素氮、C-反应蛋白）有相关性但准确性不佳；评分系统（APACHEⅡ、Ranson、BISAP等）存在不足。
- 严密监测生命体征及器官功能障碍至关重要，出现器官功能障碍应入ICU。

- **推荐意见6**：目前无准确SAP预测系统，应严密监护器官功能，警惕SAP。（证据等级：中；推荐强度：强烈推荐）

### 病程分期
- 早期（发病≤2周）：以SIRS及器官功能障碍为特点，局部并发症非主要决定因素。
- 后期（>2周）：可能持续SIRS、器官功能障碍、局部并发症；持续SIRS和器官功能障碍是严重程度的重要决定因素，感染性并发症影响预后。

- **推荐意见7**：病程分早期(≤2周)和后期(>2周)，对应两个死亡高峰，病情可能有重叠。（证据等级：中；推荐强度：一般性推荐）

### 并发症
- 全身并发症：SIRS、脓毒症、MODS、腹腔高压、ACS。
- 局部并发症：
  - 早期(<4周)：急性胰周液体积聚、急性坏死物积聚(ANC)
  - 后期(>4周)：胰腺假性囊肿(PP)、包裹性坏死(WON)
  - 均可为无菌性或感染性。
- 其他：消化道出血、腹腔出血、胆道梗阻、肠梗阻、肠瘘等。

**表4 急性胰腺炎局部并发症临床特点**
| 并发症 | 临床特点 |
|--------|----------|
| 急性胰周液体积聚 | 病程早期，胰周或胰腺远隔间隙液体积聚，缺乏完整包膜，单发或多发 |
| 急性坏死物积聚 | 病程早期，混合有液体和坏死组织，包括胰腺实质或胰周组织坏死 |
| 胰腺假性囊肿 | 起病≥4周后形成，有完整非上皮性包膜包裹的液体积聚 |
| 包裹性坏死 | 起病≥4周后，界限清晰炎性包膜的囊实性结构，包含胰腺和/或胰周坏死组织 |

## 急性胰腺炎的治疗

### 早期治疗

#### 液体治疗
- 诊断后即刻启动，SAP可采用目标导向治疗。
- 晶体液首选（乳酸林格液、生理盐水）。
- 初始速度：5\~10mL/(kg·h)。
- 复苏目标：尿量>0.5mL/(kg·h)、平均动脉压>65mmHg、中心静脉压8\~12mmHg、中心静脉血氧饱和度≥70%；动脉血乳酸、尿素氮、血细胞比容下降提示有效。
- 持续低血压可给予去甲肾上腺素。

- **推荐意见8**：确诊患者应使用晶体液，以5\~10mL/(kg·h)速度即刻液体治疗。（证据等级：中；推荐强度：强烈推荐）

#### 急诊ERCP治疗
- 不推荐对预测为轻症者行急诊ERCP；APEC研究证实急诊ERCP对预测重症患者亦无帮助。
- 仅适用于胆源性胰腺炎合并胆管炎（入院24h内），或存在持续性胆道梗阻（72h内可考虑）。

- **推荐意见9**：急诊ERCP无助于缓解胆源性AP病情，仅适用于合并胆管炎及持续胆道梗阻者。（证据等级：高；推荐强度：强烈推荐）

#### 镇痛治疗
- 明显疼痛者入院24h内接受镇痛。阿片类和非甾体抗炎药有效性和安全性证据有限。
- 非气管插管患者，盐酸二氢吗啡酮镇痛效果优于吗啡和芬太尼。
- 长期大剂量阿片类药物使用的SAP/CAP可考虑硬膜外镇痛，可能降低30d病死率。
- 推荐按围手术期急性疼痛方式（全身+局部给药，自控+多模式联合）。

- **推荐意见10**：镇痛是重要辅助治疗，可能改善预后，应合理选择药物与方式。（证据等级：中；推荐强度：一般性推荐）

#### 营养支持治疗
- 肠内营养优于肠外营养，降低感染性并发症、MODS和死亡发生率。
- 鼻胃管与鼻空肠管耐受性及并发症无差异，鼻胃管更便捷；但胃排空延迟或幽门梗阻时使用鼻空肠管。
- 发病24\~48h内启动肠内营养，48h内启动比延后更有效（更低感染和器官功能障碍发生率及病死率）。24h与72h启动住院感染率和病死率无差异，早期启动安全。
- 低脂软食安全；氨基酸型较整蛋白型无额外获益。

- **推荐意见11**：在胃肠功能耐受下，应尽早经口或肠内营养。（证据等级：高；推荐强度：强烈推荐）
- **推荐意见12**：不能经口进食者，肠内营养优于肠外营养。（证据等级：高；推荐强度：强烈推荐）

#### 高甘油三酯血症性AP的早期治疗
- 更严重的临床表现。诊断：静脉乳糜状血或血甘油三酯>11.3mmol/L。
- 早期治疗：禁食水≥24h后饮食调节，使用降血脂药物，辅助降脂（小剂量低分子肝素、胰岛素、血脂吸附和/或血浆置换）。
- 目标：尽快将甘油三酯降至5.65mmol/L以下。

- **推荐意见13**：静脉乳糜状血或血甘油三酯>11.3mmol/L可诊断，需综合治疗快速降低甘油三酯。（证据等级：中；推荐强度：强烈推荐）

#### 腹腔间隔室综合征（ACS）的早期处理
- SAP可合并ACS，腹内压>20mmHg时常伴新发器官功能障碍，是死亡重要原因。
- 治疗：增加腹壁顺应性（镇痛、镇静、肌松药）、清除胃肠内容物（胃肠减压、灌肠、促动力药）、避免过量输液、引流腹腔或腹膜后积液（PCD）。
- 不建议早期将ACS作为开腹手术指征。

- **推荐意见14**：ACS是早期死亡重要原因，需综合措施降低腹内压，不建议早期开腹手术。（证据等级：中；推荐强度：强烈推荐）

#### 预防性使用抗菌药物
- 预防性使用不能降低胰周或胰腺感染发生率，可能增加多重耐药菌及真菌感染机会。
- 无感染证据不推荐预防性用药；可疑或确诊胰腺/胰周或胰外感染，可经验性使用，并依据培养和药敏调整。

- **推荐意见15**：不推荐常规使用抗菌药物预防胰腺或胰周感染。（证据等级：高；推荐强度：强烈推荐）

#### 药物治疗
- 缺乏特异性药物。生长抑素及其类似物治疗价值缺乏高质量证据。
- 中药（大黄、芒硝、清胰汤、大承气汤等）有助于促进胃肠道功能恢复，减轻腹痛腹胀，可选择使用。

### 后期治疗
后期主要针对局部并发症，持续的器官功能障碍是预后不佳的独立危险因素。无症状的PP及WON无需处理，WON合并感染是主要处理对象。

#### 感染性胰腺坏死（IPN）的诊断
- IPN包括早期ANC合并感染和后期WON合并感染。
- 提示：发热、腹痛，严重者全身情况恶化，出现肾功能、呼吸功能不全、凝血异常、循环不稳定。
- 实验室：白细胞、C-反应蛋白、IL-6、降钙素原动态监测有助于诊断和疗效判断，降钙素原可早期评估预后。
- CT“气泡征”是IPN诊断的直接证据。不推荐常规细针穿刺抽吸检查。

- **推荐意见16**：出现发热、腹痛、全身状况恶化等感染症状时应考虑IPN可能。（证据等级：中；推荐强度：强烈推荐）
- **推荐意见17**：对怀疑IPN者行包括降钙素原在内的炎症指标及CT检查；不建议常规细针穿刺抽吸检查。（证据等级：高；推荐强度：强烈推荐）

#### IPN的治疗
- 约30%坏死性胰腺炎继发感染，病死率30%。
- 治疗手段：抗菌药物、PCD或内镜下穿刺引流、外科视频辅助清创或内镜下清创、开腹手术。
- 抗菌药物经验性使用，依据药敏调整。PCD或内镜下引流可使部分患者免于手术。微创清创成为主流，开腹手术为补充。

- **推荐意见18**：IPN常需手术治疗，抗菌药物及穿刺引流可使部分患者免于手术；微创清创逐渐成为主流，开腹手术为补充。（证据等级：中；推荐强度：强烈推荐）

#### IPN的手术策略
- 首选“Step-up”策略：先穿刺引流，效果不佳依次视频辅助清创和开腹手术。
- 对于器官功能正常、全身状态良好、无需通过PCD改善者，或缺乏安全穿刺入路、预计PCD效果不佳者，可直接手术。

- **推荐意见19**：IPN患者治疗以“Step-up”策略为主。（证据等级：高；推荐强度：强烈推荐）
- **推荐意见20**：部分经严格选择的病例，可直接行手术治疗。（证据等级：低；推荐强度：强烈推荐）

#### 外科与内镜“Step-up”的选择
- 两者病死率与严重并发症发生率无明显差异。
- 内镜优势：降低胰瘘及切口疝发生率，但操作次数多，不适用于所有IPN（如结肠后间隙及盆腔腹膜后区域感染受限）。
- 现阶段多数中心仍首选外科“Step-up”。

- **推荐意见21**：外科或内镜“Step-up”各具优势，目前多数中心仍首选外科“Step-up”。（证据等级：高；推荐强度：强烈推荐）

#### 经皮及内镜下穿刺引流的指征与时机
- 影像学或内镜引导下穿刺置管是控制感染的重要措施。PCD首选经腹膜后路径；内镜下经胃壁或十二指肠壁引流。
- 高度可疑或确诊胰腺坏死感染，即使未形成完整包裹，药物治疗不佳时PCD安全有效；早期内镜下引流可能同样安全。
- ACS合并大量腹腔或腹膜后积液，应穿刺引流降低腹内压；后期局部并发症压迫消化道或胆道时也可引流。

- **推荐意见22**：胰腺或胰周感染是PCD和内镜下穿刺引流的重要指征，可在病程早期进行。（证据等级：中；推荐强度：强烈推荐）
- **推荐意见23**：合并ACS的大量腹腔或腹膜后积液，可穿刺引流；应早期(<72h)拔除引流管以减少继发感染。（证据等级：低；推荐强度：一般性推荐）

#### IPN的手术时机
- 早期手术病死率>50%，延迟手术可降低并发症和病死率。指南推荐延迟至发病4周后。
- 现有证据来自开腹手术，微创手术时机是否需调整待研究。

- **推荐意见24**：目前IPN手术干预时机为发病4周后。（证据等级：中；推荐强度：强烈推荐）

#### 胰瘘与胰管断裂综合征（DPDS）的处理
- 20%\~40%坏死性胰腺炎可伴胰管部分或完全中断，WON合并DPDS比例最高。
- MRCP评估胰管完整性。
- 治疗：通畅引流、抑制胰腺分泌。内镜治疗首选：WON经腔内引流后建议长期留置双猪尾塑料支架减少复发；部分主胰管破裂可考虑支架桥接，完全破裂可EUS引导下主胰管引流。内镜失败或复发积液可选择手术（胰腺远端切除、Roux-en-Y引流）。

- **推荐意见25**：DPDS患者首选内镜下治疗。（证据等级：中；推荐强度：强烈推荐）

#### 门静脉、脾静脉血栓形成及胰源性门静脉高压
- 门静脉、脾静脉血栓发生率约13%，严重可致肝功能衰竭、门静脉高压、脾和肠道坏死。
- 抗凝治疗未提高血管再通率，反而增加出血风险，不建议抗凝。
- 胰源性门静脉高压：多数无症状可随访；上消化道大出血时除止血外，积极处理胰腺原发病；反复出血考虑脾切除；严重脾功能亢进可脾动脉栓塞或脾切除。

- **推荐意见26**：急性胰腺炎后门静脉、脾静脉血栓常见，可表现左侧门静脉高压，无需抗凝治疗。（证据等级：低；推荐强度：一般性推荐）

#### 肠瘘、腹腔出血的处理
- 结肠瘘常见，治疗：通畅引流、造口转流。
- 腹腔出血：先行血管造影明确，动脉性出血行血管栓塞；未明确或栓塞失败、出血持续可行手术。

## 复发预防及随访

### 复发性急性胰腺炎（RAP）
- 约21%首发AP进展为RAP，定义：≥2次发作，间隔≥3个月。
- 病因治疗是预防关键：胆囊切除术预防胆源性复发；高甘油三酯血症低脂饮食、减重，控制不佳口服降脂药；戒酒预防酒精性复发。

- **推荐意见27**：约1/5患者进展为RAP，病因治疗有助于预防复发。（证据等级：中；推荐强度：强烈推荐）

### 胆源性胰腺炎胆囊切除时机
- 腹腔镜胆囊切除术是预防复发主要手段。
- MAP伴胆囊结石，排除胆总管结石，建议当次发病出院前完成。
- MSAP及SAP：发病后1\~3个月实施。

- **推荐意见28**：胆源性胰腺炎合并胆囊结石，推荐尽早行胆囊切除术。（证据等级：高；推荐强度：强烈推荐）

### 随访
- AP后1年内胰腺外分泌功能不全发生率61%\~85%，部分持续6\~18个月；约1/3出现内分泌功能不全；约40%出现糖尿病或前驱表现。
- 规律随访：MAP至出院后6个月，MSAP及SAP至少至18个月。每6个月评估胰腺功能，注意远期并发症及病因是否去除。

- **推荐意见29**：康复后需规律随访，及时发现并治疗远期并发症。（证据等级：弱；推荐强度：一般性推荐）
