# 肠结核的诊断与治疗重要信息索引

## 诊断

### 临床特点
- 好发部位：回盲部，青壮年多见，女性略多于男性，常伴有肺结核。
- 主要表现为腹痛（右下腹或脐周隐痛）、腹部包块（回盲部居多）、腹泻与便秘、月经紊乱、全身结核中毒症状（低热、盗汗、乏力、纳差、体重下降）。
- 体格检查：半数以上可触及腹部包块，位于右下腹，质地硬，表面不平，有压痛，相对固定。合并肠梗阻、穿孔或局限性腹膜炎时有相关体征。

### 实验室检查
- PPD试验阳性有参考价值，但特异性及灵敏性不高，阴性不能完全排除。
- 伴有活动性肺结核者痰培养阳性。
- 腹水检查：草绿色渗出液，静置凝固，ADA>40 U/L可诊断结核性腹水。
- 可有血沉加快、贫血。

### 影像学检查
- X线钡餐/结肠双对比造影：多发溃疡、粘膜集中、肠腔狭窄、结肠袋变浅消失、肠道痉挛激惹征，呈“跳跃征”；盲升结肠变形缩短、回盲瓣增厚，回肠末端狭窄，与盲肠排列成直线呈“一字征”。
- CT：肠壁环形增厚，少数盲肠内侧偏心性增厚，回盲瓣增厚，跳跃性改变，均匀强化；可见环形或多环状强化的肿大淋巴结，少数钙化。

### 纤维结肠镜
- 炎症型：粘膜充血水肿、糜烂，附黄白色渗出物。
- 溃疡型：大小不等溃疡，椭圆形或类圆形，横形走向，与肠轴垂直，底部覆黄白苔，周围炎症。
- 增生型：铺路石样增生性结节，可形成不规则肿物隆起，质脆易出血。
- 混合型：肠腔节段性狭窄。

### 病理
- 肠壁全层慢性炎症、溃疡深，干酪样坏死，结核结节（干酪样肉芽肿）；抗酸染色可找到阳性杆菌。活检干酪样坏死少见可能与取材有关。

### 诊断性抗结核治疗
- 抗结核治疗2～3周后症状好转，可诊断结核病。

### 诊断要点
1. 有结核病史或肺结核等肠外结核病灶。
2. 腹痛、腹泻与便秘、腹部包块。
3. 结核中毒症状。
4. 可有轻度贫血、血沉增快、痰培养阳性，PPD试验阳性有参考价值。
5. X线钡餐造影或结肠双对比造影显示肠管激惹征、充盈缺损、肠腔狭窄。
6. CT多表现为肠壁环形增厚，少数盲肠内侧偏心性增厚，回盲瓣增厚。
7. 纤维结肠镜下见肠道炎症、溃疡和增生性病变；溃疡椭圆形或类圆形，横形走向，与肠轴垂直；增生型呈铺路石样改变，可形成不规则肿物。
8. 病理组织学检查见结核结节，抗酸染色发现结核杆菌。

## 治疗

### 支持与对症治疗
- 充分休息和合理营养，必要时肠外或肠内营养。
- 腹痛给予解痉止痛；腹泻给予止泻并补液、维持水电解质酸碱平衡。

### 抗结核治疗
- 原则：早期、规律、全程、适量、联合用药。
- 肺外结核与肺结核采用相同方案。
- 常用药物：异烟肼（INH，H）、链霉素（SM，S）、利福平（RFP，R）、乙胺丁醇（EMB，E）、吡嗪酰胺（PZA，Z）。
- 复方制剂：异烟肼利福平吡嗪酰胺（卫非特，RIFATER，每片含利福平120 mg、异烟肼80 mg、吡嗪酰胺250 mg）；异烟肼利福平（卫非宁，RIFINAH，每片含利福平150 mg、异烟肼100 mg）。
- 治疗方案包含两个阶段：强化期和巩固期。
- 推荐方案：2HRZE/4HR（6个月利福平治疗），2HRZE/6HE已逐渐停用。

### 手术治疗
适应症：
- 完全性肠梗阻；
- 急性肠穿孔，或慢性肠穿孔瘘管形成经内科治疗未能闭合；
- 肠道大量出血经积极抢救不能有效止血；
- 诊断困难需剖腹探查；
- 反复发作的慢性肠梗阻，严重影响工作生活，伴营养障碍。

手术方式：肠粘连松解术、病变肠段切除术、病灶清除术、腹腔引流术等。术后继续规范抗结核治疗。
