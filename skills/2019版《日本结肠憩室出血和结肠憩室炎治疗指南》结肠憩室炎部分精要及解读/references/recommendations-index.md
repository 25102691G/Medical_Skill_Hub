# 日本结肠憩室出血和结肠憩室炎治疗指南（2019版）重要信息索引

## 指南背景

- 日本胃肠病协会等四个学会共同制定了首部《日本结肠憩室出血和结肠憩室炎治疗指南》，于2019年正式发布。该指南基于GRADE标准，以临床问题形式给出证据等级和推荐强度。中国结肠憩室发病率为0.2%~1.9%，60岁以上患病率明显提高但不超过5%。
  - 原文位置：`L000025-L000025`

## 患病率

- 日本平均年龄52岁人群中结肠憩室患病率为23.9%，低于西方。憩室多发生于右侧结肠，左侧比例随年龄增长而增加，存在种族差异。
  - 原文位置：`L000029-L000029`

## 临床评估

- 无脓肿或穿孔的结肠憩室炎常见症状为腹痛，体征为局限于憩室部位的压痛，可伴发热、恶心、呕吐。实验室检查常见白细胞计数增多、C反应蛋白水平升高、血沉加快。鉴别诊断包括肠易激综合征、肠胃炎、肠梗阻、肠道炎性疾病、阑尾炎、缺血性结肠炎、结直肠癌、泌尿系感染、肾结石及妇产科疾病。仅凭体格检查和实验室检查不足以鉴别诊断，需同时进行影像学检查，影像学结果是憩室炎分级系统建立的基础，被作为金标准推荐。超声诊断能力可与CT相媲美，对孕妇可作为首选，但受检查者水平、肠胀气、按压力度、肥胖等因素影响；欧美仅推荐用于CT有相对禁忌证者（妊娠、肾功能不全、造影剂过敏等）。憩室炎缓解后建议至少行一次结肠镜检查以排除炎性肠病、结肠癌等其他病变，急性期行结肠镜检查可能加重炎性反应或致穿孔，需慎重。
  - 原文位置：`L000033-L000033`

## 影像学分级

- 乙状结肠憩室炎穿孔分级评分（WSES基于CT影像）：IA级为可见蜂窝组织炎，无脓肿；IB级为可见蜂窝组织炎，脓肿≤4cm；Ⅱ级为可见蜂窝组织炎，脓肿>4cm；Ⅲ级为化脓性腹膜炎（结肠未穿孔）；Ⅳ级为穿孔性腹膜炎（结肠穿孔）。
  - 原文位置：`L000035-L000037`

## 内科及介入治疗

### 单纯性憩室炎

- 对于没有脓肿和穿孔的单纯性憩室炎，治疗包括限制饮食、肠道休息及抗生素治疗。抗生素治疗能否获益存在争议，欧美随机对照研究显示使用抗生素并未降低复发率或并发症发生率，但研究存在随机不完全、排除高危患者等问题，且亚洲缺乏类似研究，因此指南认为临床使用抗生素可以接受，但需进一步研究。免疫功能低下患者憩室炎发病率及并发脓肿或穿孔几率明显升高，需使用抗生素预防进展；孕妇需与产科医生讨论后决定是否使用抗生素。
  - 原文位置：`L000041-L000041`

### 脓肿形成

- 脓肿形成但未穿孔且表现为局限性腹膜炎的患者，限制饮食、肠道休息及抗生素治疗仍作为一线方案。脓肿直径≤3cm者上述治疗即可；≥5cm者仅抗生素治疗效果有限，建议加做超声或CT引导下脓肿引流；3~5cm者需根据病情和引流可行性个体化治疗，还需考虑人力和医疗设施资源。WSES建议引流直径为4cm，但本指南认为证据不足。
  - 原文位置：`L000043-L000043`

## 外科治疗

### 手术指征与方法

- 外科治疗的指征包括：抗生素治疗和脓肿引流无效或无法引流的大脓肿；Hinchey Ⅲ~Ⅳ级憩室炎；无法控制的败血症；复杂性憩室炎伴临近脏器（膀胱、子宫、阴道、肾脏和皮肤等）瘘管形成；合并肠道狭窄；不能除外癌时。常用手术方法有Hartmann手术、结肠切除术和腹腔引流术。腹腔镜手术在术后并发症严重程度和住院时间方面比开腹手术更具优势，指南未给出明确适应证，择期手术更适用，但急诊及复杂性手术并非绝对禁忌，应根据患者情况和术者经验综合考虑。复杂性憩室炎伴瘘管形成者手术难度较大，建议由熟练外科医生进行。左半结肠及乙状结肠更易因憩室炎造成狭窄且难以自行缓解，建议炎性反应消退后择期手术，可降低穿孔及死亡风险和永久性结肠造口的可能。
  - 原文位置：`L000047-L000047`

### 预防性切除争议

- 历史上ASCRS、EAES和ACG曾建议有两次急性憩室炎发作史或50岁以下有1次发作史者行预防性结肠切除术，但近年研究质疑此适应症。大多数憩室炎首次发作并出现并发症者保守治疗后复发长期风险很低，仅2%~5%的复发性憩室炎患者新发脓肿或穿孔需紧急手术，且复发时不一定伴脓肿。指南建议单纯性及复杂性憩室炎复发后不一定行择期结肠切除术，应首选保守治疗；但免疫功能低下者可考虑择期手术。免疫功能低下或接受免疫抑制治疗、慢性肾功能衰竭或胶原血管病患者急性复发时穿孔风险增加5倍，可能从早期选择性切除中获益。
  - 原文位置：`L000049-L000049`

## 药物预防

- 预防结肠憩室炎复发方面：增加膳食纤维摄入、口服不可吸收抗生素利福昔明等研究结论缺乏说服力，摄入益生菌被认为没有预防作用，仅能缓解部分腹部症状。目前缺乏高质量证据支持任何药物预防复发，需进一步研究。
  - 原文位置：`L000053-L000053`
